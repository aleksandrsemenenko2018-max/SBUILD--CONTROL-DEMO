# Тести S-BUILD Control

Для локального запуску потрібні Node.js 22 або новіша версія та Chromium.

```sh
npm ci
npx playwright install chromium
npm test
```

`npm run test:auth` запускає 19 сценаріїв входу й реєстрації.
`npm run test:unit` запускає модульні тести.

Сценарії відкривають HTML та модулі з робочої копії. Браузер завантажує клієнт Supabase з `esm.sh`, а тестова обгортка відповідає на запити до Supabase фіктивними даними. Інші мережеві запити блокуються. Тести не потребують справжніх облікових записів, ключів із підвищеними правами або доступу до робочої бази.

Якщо Chromium уже встановлено, вкажіть шлях до виконуваного файла в `BROWSER_TEST_CHROMIUM`. У середовищі з HTTPS-проксі можна вказати його адресу в `BROWSER_TEST_PROXY`. За потреби `BROWSER_TEST_PROXY_SPKI` приймає Base64-відбиток SHA-256 відкритого ключа сертифіката проксі для `esm.sh`.
